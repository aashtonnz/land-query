# `land-query` (TopoNZ / TopoAU Plot Context Spine)

A local SQLite + FTS5 compiler, 12-physics-simulation engine, and Model Context Protocol (`MCP`) server that joins New Zealand and Australian land, building, natural-resource, and satellite data onto a single `parcel_id` for `$0.00` out-of-pocket infrastructure cost.

## What exists now vs. what is planned

- **What exists now in this repository**:
  1. **`toponz_weekend1_kapiti_ingester.py`**: A zero-dependency Python (`sqlite3` + `numpy`) compiler and JSON-RPC 2.0 `MCP` server implementing the 96-domain (`2,746`-primitive, 17-table) relational schema, 12 vectorized `NumPy` physics kernels (`SIM-01` to `SIM-12`), a deterministic statutory regex/AST parser (with imperial-to-metric conversion), a 15-pillar (`64`-invariant) cross-checking engine, and a **fictional** 3-parcel demonstration dataset (`10 Example St`, `16 Sample St`, `114 Specimen Rd`): the addresses, facts, identifiers and companies are invented, and real data comes only from [`pipeline/tile_test`](pipeline/tile_test/).
  2. **`index.html` (`nz_topological_parcel_engine.html`)**: A 37-tab interactive reference web application for inspecting the schema, physics kernels, 6-layer SVG visual compositor, cross-checking rules, and MCP payloads.
  3. **`schemas/*.json`**: 17 JSON schema catalogs and benchmark outputs generated by the compiler.
- **What is planned next** (tracked in [`TASKS.md`](TASKS.md) `T-16` to `T-27`):
  - Connecting the `1 km × 1 km` tile batch compiler on a local internet-connected machine to live LINZ Data Service WFS/LiDAR, GWRC Open Data, KCDC Rating/Consent feeds, and Element84 Sentinel-2 STAC COGs to hydrate all 54 Kāpiti Coast tiles (`24,800` parcels).

## Quickstart

```bash
# 1. Compile the local SQLite WAL + FTS5 benchmark database and run the 15-pillar self-test (~75 ms)
python3 toponz_weekend1_kapiti_ingester.py --self-test

# 2. Generate a unified 96-domain JSON dossier for a benchmark parcel (<5 ms)
python3 toponz_weekend1_kapiti_ingester.py --dossier DEMO-5041821
python3 toponz_weekend1_kapiti_ingester.py --dossier DEMO-5042110

# 3. Run the JSON-RPC 2.0 MCP server over stdio
python3 toponz_weekend1_kapiti_ingester.py --serve-mcp
```

### Register in Claude Desktop or Cursor (`claude_desktop_config.json`)

```json
{
  "mcpServers": {
    "land-query": {
      "command": "python3",
      "args": ["/absolute/path/to/land-query/toponz_weekend1_kapiti_ingester.py", "--serve-mcp"]
    }
  }
}
```

## Schema Structure (`96 Domains · 17 SQLite Tables`)

| Table in `toponz_weekend1_kapiti_ingester.py` | Domains | Purpose |
| :--- | :--- | :--- |
| `plot_spine_58d` & `dp_instrument_registry` | `D01–D58` | Cadastral geometry, easements, Shared-DP (`1:64`) instrument deduplication, pipe inverts, CPT geotech, and 12 `NumPy` physics simulations (`SIM-01` to `SIM-12`). |
| `plot_verbatim_fts5` | `D02, D12, D53` | SQLite FTS5 full-text index over title memorials, `s42A` consent reports, and 1970s drainage tie cards. |
| `parcel_adjacency_edges` | `D23, D27` | Shared boundary graph between touching parcels for cross-boundary gravity sewer and view-covenant trades. |
| `plot_buildings_and_units_64d` | `D59–D64` | `1:N` building and unit sub-spine: bedrooms, bathrooms, RID vs. LiDAR floor-area deltas, cladding, Healthy Homes, `%NBS`, `CCC` status, and house-relocation salvage value. |
| `plot_natural_resources_70d` | `D65–D70` | Minerals/aggregates, freshwater takes, `LUC`/`NPS-HPL` soils, `LCDB v6.0`, ETS Pre-1990/Post-1989 carbon, solar/wind/geothermal, and `20m` esplanade strips. |
| `plot_satellite_eo_and_visual_layers_72d` | `D71–D72` | `5cm` LINZ Basemaps WMTS template, Sentinel-1 InSAR, Sentinel-2 `NDVI`/`NDWI`, Landsat-9 thermal, and 6-layer visual stack metadata. |
| `plot_indirect_inferences_78d` | `D73–D78` | 6-modality, 36-signal non-invasive X-ray inferences (SAR dielectric leaks, `2.32μm` SWIR asbestos, nocturnal roof thermal `ΔT`, LiDAR wire sag, curbside bin/meter counts, Chorus ONTs, shadow signals). |
| `plot_crosscheck_reconciliation_80d` & `cross_silo_contradictions_70d` | `D79–D84` | 15-pillar, 64-invariant multi-witness cross-checker (`Wgtn1953` to `NZVD2016` datum fixes, Kirchhoff pipe monotonicity, Cross-Lease Flats-Plan checks, `MBIE` solvency, 5-tier statutory lattice). |
| `cadastral_lineage_dag_85d` & `ancestral_farm_to_lot_backfill_90d` | `D85, D89–D90` | Parent-to-child subdivision (`1→N`) and amalgamation (`N→1`) DAG plus coordinate-first `1860→2026` farm-to-lot sub-polygon backfill (5-class inheritance algebra). |
| `parcel_split_zoning_and_epochs_86d` | `D86` | Intra-parcel `ST_Intersection` split-zoning slices and `1973→2026` District Plan epoch history for `s10` Existing Use Rights. |
| `non_private_and_special_tenure_88d` & `advanced_mutations_zoning_and_crown_estate_96d` | `D87–D88, D91–D96` | DOC conservation land (`NaPALIS`), council reserves, paper roads, hydro riverbeds, Māori Freehold / `s338` land, 3D strata, `s176` Designations, Environmental Benefit `TDR` credits, Crown `RFR`s, and `s40` offer-back checks. |
| `watchtower_endpoint_registry` & `tile_checkpoint_manifest` | Ops | 108-agency endpoint surveillance registry and `1 km × 1 km` `NZTM2000` crash-resumable tile batch checkpoints. |
