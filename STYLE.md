# Style

Follows: style guide v1 (ai-working-practices)

- **Tone**: Calm, direct, utilitarian, and factual. Describe what the software and data do without sales language, hype, or exclamation marks.
- **Claims**: Keep what exists now (the live pipeline and the compiled Kāpiti Coast district) clearly separate from what is planned (the rest of Kāpiti Coast, a query service, other councils). Label each value as published, derived or modelled. Avoid completeness words ("every", "all", "100%") unless literally true of the rows in the database.
- **Spelling**: New Zealand English (`metre`, `paraparaumu`, `programme`, `licence`, `cadastral`, `Māori` with macrons).
- **Typeface & UI**: System sans-serif (`Inter` / system UI) for prose and labels; monospace (`JetBrains Mono` / `Fira Code`) for parcel IDs, SQL queries, coordinates, elevations (`RL`), and SHA-256 hashes. High-contrast slate/zinc surfaces meeting WCAG AA contrast.
