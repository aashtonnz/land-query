# Decisions

Newest first. Each decision has a permanent ID and short name.

- **D-12: Product scope: an area-queryable parcel fact service for agents (2026-11-06)**: Land Query answers area queries from AI agents ("which parcels match these conditions?") with the source, fetch time, licence and fit-for-parcel flag on every value, and each value marked as published, derived or modelled (with method). Collect anything that is lawful to obtain and whose source terms allow automated use; tag each source's licence, and serve only cleared data to outside users. Facts and inferences are about land and buildings, never about people: no owner or director networks, no occupant profiling. Nothing invented. Compute any measure that is cheap to derive, checking each one against something independent before it ships. Starts with Kāpiti Coast and grows one council at a time. Restates D-1 more narrowly; supersedes D-2 to D-9 where they conflict. [Proposal](docs/proposals/2026-11-06-reset.md) (`T-32`).
- **D-14: Small, expected GitHub costs instead of $0 (2026-11-07)**: The free 3,000 Actions minutes were used up in November 2026 (about US$6.79 of paid usage by then). The owner accepts small, expected bills within a monthly GitHub budget, US$10 now, raised by $10 at a time when asked, but no surprise bills. Agents estimate each run's cost beforehand and keep the month's total. Supersedes the "$0.00" part of project rule 1.
- **D-13: Parcel geometry from LINZ; KCDC's mirror for district membership only (2026-11-07)**: Each parcel's geometry and fields come from LINZ NZ Primary Parcels (layer 50823) by parcel id, fetched with the repository key on GitHub. KCDC's mirror decides which parcels belong to the district and to each block, and is kept as a QA cross-check. The reason: the mirror truncates some parcels lying wholly inside the district (39 in block 1785000_5485000), so values compiled on it described fragments. Without the key (a local session) the mirror is used and marked in `geometry_source` (`T-51`, supersedes D-11 for geometry).
- **D-11: Kāpiti parcels from KCDC's public LINZ mirror (2026-11-06)**: Fetch primary parcels from KCDC's public `Cadastral` map service rather than LINZ WFS, because it needs no key, carries the same LINZ fields and ids, and matched LINZ areas to within 0.5 m² in the test tile. Attribute LINZ (CC BY 4.0). Titles, easements and other regions use LINZ WFS. Checked against LINZ: identical for shared parcels, no lag, railway parcels omitted (`T-33`, `T-34`). *Superseded for geometry by D-13 (7 Nov 2026): the mirror truncates some parcels lying inside the district.*
- **D-10: Adopt `ai-working-practices` (2026-11-06)**: Organise project tracking, risk management, and external communication under `github.com/aashtonnz/ai-working-practices` (Task board v1.9, Style guide v1, Risk list v1.1, changelog to entry 32) so task IDs, decisions, and risks stay consistent across sessions and tools (`T-14`).
- **D-9: Coordinate-first `NZTM2000` ancestral backfill with 5-class inheritance algebra (2026-11-06)**: Because pre-1998 historical farm records lack modern LINZ `parcel_id`s and naive parent-to-child broadcasting smears all child lots of a subdivided farm with localized hazards (such as a single 1954 sheep-dip), intersect modern parcel polygons directly against georeferenced `NZTM2000` historical sub-polygons (`D89–D90`, `T-12`). *Superseded in part by D-12: ancestral backfill is deferred with lineage (not in v1).*
- **D-8: Model dynamic parcel splits/joins as a DAG, slice split-zoned plots, and index non-private land (2026-11-06)**: Track `1→N` subdivisions and `N→1` amalgamations in `cadastral_lineage_dag_85d`, slice multi-zoned parcels into exact `ST_Intersection` sub-polygons (`D86`), and index adjoining DOC conservation land, council reserves, paper roads, hydro beds, Crown RFR/s40 land, and Māori Freehold land (`D87–D88`, `D91–D96`, `T-11`, `T-13`). *Superseded in part by D-12: lineage DAG and split-zoning deferred; non-private land kept.*
- **D-7: 15-pillar multi-witness cross-checking over raw single-silo trust (2026-11-06)**: Reconcile conflicting government silos (`D79–D84`) using multi-sensor quorums (e.g., tying manhole rims to `NZVD2016` LiDAR to fix `+0.38m` `Wgtn1953` datum shifts, and requiring 4-of-5 physical/utility witnesses before flagging an unconsented flat) (`T-09`). *Superseded by D-12: the 15-pillar cross-checker is replaced by a short set of QA checks run on every tile.*
- **D-6: Free LINZ `5cm` aerials + open Sentinel-1/2 STAC COGs instead of paid commercial satellites (2026-11-06)**: Skip `$10,000+/yr` Planet Labs subscriptions; use free `5cm–10cm` LINZ Basemaps WMTS/XYZ orthophotos for spatial resolution and free Element84/Copernicus Sentinel-1 InSAR and Sentinel-2 5-day multispectral COGs for temporal and non-visible bands (`D71–D78`, `T-07`, `T-08`). *Superseded in part by D-12: LINZ aerials kept; Sentinel imagery only as labelled area context, never a parcel fact.*
- **D-5: Separate `1:N` building sub-spine and 6-domain natural resource sub-spine (2026-11-06)**: Represent buildings and units in a `1:N` child table (`plot_buildings_and_units_64d`, `D59–D64`) rather than a single flat column on the parcel, and model minerals, freshwater takes, `LUC`/`NPS-HPL` soils, ETS carbon, renewable energy, and esplanade strips in `plot_natural_resources_70d` (`D65–D70`, `T-04`, `T-05`). *Superseded in part by D-12: building interiors from listings and rating detail deferred pending a lawful source; natural resources deferred.*
- **D-4: Autonomous 108-agency endpoint Watchtower and auto-assimilation (2026-11-05)**: Probe NZ/AU council and agency domains weekly for new `/.well-known/mcp.json`, `/llms.txt`, STAC, and DCAT-AP `/data.json` feeds so any newly launched agency API can be wrapped as a free upstream source (`T-02`). *Superseded by D-12: watch only the sources in use, weekly, for field and record-count changes (T-25).*
- **D-3: Pre-compute 12 unopinionated physics simulations alongside raw data (2026-11-05)**: Keep raw statutory and physical primitives untouched, but pre-compute 12 expensive 3D spatial/physics calculations (`SIM-01` to `SIM-12`: horizon angles, 7-threshold cut/fill curves, D-infinity overland flow, 3D roof planes, HIRB shadow cones, multi-main sewer fall, wind multipliers, acoustics, CPT LSN liquefaction, historical stereo fill diffs, swept paths, and slope-weighted walk isochrones) using local `NumPy` because LLM agents cannot run 3D raster physics at query time (`T-01`). *Amended by D-12: compute any cheap measure (sun, shading, views, overland flow, roof planes, cut/fill, wind exposure) with one independent check each; defer those needing data we lack.*
- **D-2: `$0.00` bootstrap via Shared-DP 1:64 deduplication and stream-and-discard LiDAR (2026-11-05)**: Eliminate the `$300k` LINZ title fee and `$18k/yr` cloud GIS bill by indexing instruments at the Deposited Plan (`DP`) level (where 1 subdivision instrument covers up to 64 sibling lots), streaming `1m` LiDAR tiles in memory and discarding raw rasters after extracting `1.8 KB/plot` primitives, and storing in SQLite WAL + FTS5 (`T-01`). *Corrected by D-12: Shared-DP reuse is about 3.7 lots per plan (T-33), not 1:64, so covenant text stays a paid search; v1 records that an instrument exists. Stream-and-discard LiDAR stands.*
- **D-1: Unopinionated plot-keyed context spine for AI agents (2026-11-05)**: Build the system as a fast (`<5 ms`), unopinionated data and physics spine keyed by `parcel_id` exposed via Model Context Protocol (`MCP`), leaving task-specific weighting and decisions to querying agents (`T-01`).
