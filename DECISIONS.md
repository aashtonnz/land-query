# Decisions

Newest first. Each decision has a permanent ID and short name.

- **D-11: Kāpiti parcels from KCDC's public LINZ mirror (2026-11-06)**: Fetch primary parcels from KCDC's public `Cadastral` map service rather than LINZ WFS, because it needs no key, carries the same LINZ fields and ids, and matched LINZ areas to within 0.5 m² in the test tile. Attribute LINZ (CC BY 4.0). Titles, easements and other regions use LINZ WFS. Checked against LINZ: identical for shared parcels, no lag, railway parcels omitted (`T-33`, `T-34`).
- **D-10: Adopt `ai-working-practices` (2026-11-06)**: Organise project tracking, risk management, and external communication under `github.com/aashtonnz/ai-working-practices` (Task board v1.9, Style guide v1, Risk list v1.1, changelog to entry 32) so task IDs, decisions, and risks stay consistent across sessions and tools (`T-14`).
- **D-9: Coordinate-first `NZTM2000` ancestral backfill with 5-class inheritance algebra (2026-11-06)**: Because pre-1998 historical farm records lack modern LINZ `parcel_id`s and naive parent-to-child broadcasting smears all child lots of a subdivided farm with localized hazards (such as a single 1954 sheep-dip), intersect modern parcel polygons directly against georeferenced `NZTM2000` historical sub-polygons (`D89–D90`, `T-12`).
- **D-8: Model dynamic parcel splits/joins as a DAG, slice split-zoned plots, and index non-private land (2026-11-06)**: Track `1→N` subdivisions and `N→1` amalgamations in `cadastral_lineage_dag_85d`, slice multi-zoned parcels into exact `ST_Intersection` sub-polygons (`D86`), and index adjoining DOC conservation land, council reserves, paper roads, hydro beds, Crown RFR/s40 land, and Māori Freehold land (`D87–D88`, `D91–D96`, `T-11`, `T-13`).
- **D-7: 15-pillar multi-witness cross-checking over raw single-silo trust (2026-11-06)**: Reconcile conflicting government silos (`D79–D84`) using multi-sensor quorums (e.g., tying manhole rims to `NZVD2016` LiDAR to fix `+0.38m` `Wgtn1953` datum shifts, and requiring 4-of-5 physical/utility witnesses before flagging an unconsented flat) (`T-09`).
- **D-6: Free LINZ `5cm` aerials + open Sentinel-1/2 STAC COGs instead of paid commercial satellites (2026-11-06)**: Skip `$10,000+/yr` Planet Labs subscriptions; use free `5cm–10cm` LINZ Basemaps WMTS/XYZ orthophotos for spatial resolution and free Element84/Copernicus Sentinel-1 InSAR and Sentinel-2 5-day multispectral COGs for temporal and non-visible bands (`D71–D78`, `T-07`, `T-08`).
- **D-5: Separate `1:N` building sub-spine and 6-domain natural resource sub-spine (2026-11-06)**: Represent buildings and units in a `1:N` child table (`plot_buildings_and_units_64d`, `D59–D64`) rather than a single flat column on the parcel, and model minerals, freshwater takes, `LUC`/`NPS-HPL` soils, ETS carbon, renewable energy, and esplanade strips in `plot_natural_resources_70d` (`D65–D70`, `T-04`, `T-05`).
- **D-4: Autonomous 108-agency endpoint Watchtower and auto-assimilation (2026-11-05)**: Probe NZ/AU council and agency domains weekly for new `/.well-known/mcp.json`, `/llms.txt`, STAC, and DCAT-AP `/data.json` feeds so any newly launched agency API can be wrapped as a free upstream source (`T-02`).
- **D-3: Pre-compute 12 unopinionated physics simulations alongside raw data (2026-11-05)**: Keep raw statutory and physical primitives untouched, but pre-compute 12 expensive 3D spatial/physics calculations (`SIM-01` to `SIM-12`: horizon angles, 7-threshold cut/fill curves, D-infinity overland flow, 3D roof planes, HIRB shadow cones, multi-main sewer fall, wind multipliers, acoustics, CPT LSN liquefaction, historical stereo fill diffs, swept paths, and slope-weighted walk isochrones) using local `NumPy` because LLM agents cannot run 3D raster physics at query time (`T-01`).
- **D-2: `$0.00` bootstrap via Shared-DP 1:64 deduplication and stream-and-discard LiDAR (2026-11-05)**: Eliminate the `$300k` LINZ title fee and `$18k/yr` cloud GIS bill by indexing instruments at the Deposited Plan (`DP`) level (where 1 subdivision instrument covers up to 64 sibling lots), streaming `1m` LiDAR tiles in memory and discarding raw rasters after extracting `1.8 KB/plot` primitives, and storing in SQLite WAL + FTS5 (`T-01`).
- **D-1: Unopinionated plot-keyed context spine for AI agents (2026-11-05)**: Build the system as a fast (`<5 ms`), unopinionated data and physics spine keyed by `parcel_id` exposed via Model Context Protocol (`MCP`), leaving task-specific weighting and decisions to querying agents (`T-01`).
